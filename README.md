# 💰 Pocket Smart AI - Your Smart Budget & Recommendation Assistant

> An intelligent, simple, and personal finance assistant that helps you save smarter.

### 🚀 About The Project
Pocket Smart AI is a Python-based console application designed to solve a common problem: **People earn but don't know where their money goes.**

Unlike complex budgeting apps, Pocket Smart AI talks to you like a friend. It analyzes your income and expenses and gives you instant, personalized financial advice to help you save more and spend wisely.

### ✨ Key Features
*   **📊 Instant Budget Analysis:** Automatically calculates your savings and savings percentage.
*   **🤖 AI-Powered Recommendations:** Gets smart tips - whether to cut expenses or start investing.
*   **💬 Conversational UI:** Simple and friendly chat-like interface.
*   **🔒 Privacy First:** All data stays on your local machine. No login needed.
*   **📈 Future Ready:** Easily extendable to graphs, expense categories, and web app.

### 🛠️ Tech Stack
*   **Language:** Python 3.11+
*   **Core Concepts:** Conditional Logic, User Input Handling, Virtual Environment
